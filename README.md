A stack VM for the [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty. `main.ts` (Node 22, no dependencies) runs a set of 40 instances, writing the programs' output and exit code per the kit's ISA: 32-bit wrapping arithmetic, a 256-value stack, a 64-deep call stack, and all ten traps. Deterministic.
